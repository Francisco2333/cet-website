基线（2026-10-20）：`dev`；只有 AGENTS.md 被修改；ESLint 9 错误、7 警告；类型通过；沙箱构建 trace 权限失败，在正常权限下构建通过，107 个静态页面。93 套真题索引；本地共 183 PDF、58 MP3；没有结构化试题或机读答案键。原许可证保持原样。

设计：沿用靛蓝色和明暗变量，减少渐变及玻璃效果；详情页即工作台。PDF/原创题干与答题区在桌面并列，移动端切换显示；音频不随题型切换卸载。真题采用教育考试院公开结构（听力25、选词10、匹配10、仔细阅读10、写作1、翻译1），使用前让学习者核对 PDF，匹配题填写实际段落字母。缺少可信答案的题不评分；示例仅显示客观题正确数，不换算官方分数。

数据、答题持久化、计分、计时和 AI 适配层均为可独立测试的 TypeScript 模块。仅新增获准的 `pdfjs-dist`，worker 和辅助资源随构建本地发布；测试使用现有 TypeScript 和 Node 内置 test。AI 密钥由根级 Provider 保存在内存，URL 和模型可持久化；请求只在点击翻译/连接测试时发送。

来源：[CET 官方试卷结构](https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm)、[PDF.js 文档](https://mozilla.github.io/pdf.js/)、已安装 Next 16.2.6 的 `node_modules/next/dist/docs/`。
