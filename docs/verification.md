## 本轮布局与翻译修复

- 桌面至少 1100px 时为约 58%/42% 左右布局，PDF 和答题区各自滚动，作文、翻译、批改、导航和提交均保留；更窄时自然上下排列。
- 三种阅读模式共用视口高度：紧凑/标准/加高以 75/80/85dvh 为目标，桌面最多 1120px，结合最小阅读高度及预留 120px 限制；手机改为约 65/70/75dvh，最多 700px。1050px 视口实测紧凑约 788px、标准 840px，三种模式一致。双页在可用宽度与高度内等比显示，滚动页码按可见比例更新，避免加高后末页回跳。
- 根因由浏览器复现：浮层按钮的 `pointerup` 冒泡到全局选区监听器，150ms 后重复捕获同一个选区，清空错误/结果并 abort 刚发出的请求。修复前本机延迟 600ms 服务记录 **1 次请求、1 次客户端取消、没有译文**；未配置提示也会消失。修复后同一脚本记录 **1 次请求、0 次取消、提示和译文均保留**。
- 修复在选区层：忽略浮层内部事件；同一文本重复检查不清理状态；缓存选区文本并阻止按钮 pointerdown 改变选区；滚动译文不关闭浮层。只有明确选取新文本、关闭或点击外部才取消旧翻译。未配置时显示用户指定提示和 AI 设置入口。
- 共享 API 层增加 HTTP 400/404/422 的地址/模型/参数提示，其余认证、额度、网络/CORS、超时与格式处理保留，独立主观题批改使用同一请求层并已回归。

复现回归脚本为 `tests/translation-click-repro.mjs`；完整浏览器测试新增 `tests/translation-browser.mjs`，验证真实 PDF 英文单词及跨行句子选择、600ms 延迟请求、选区不丢、长译文内部滚动、错误持久展示、重试和 25 秒超时。超时通过浏览器时钟推进触发真实 AbortController，不修改生产超时参数。请求过程同一个 audio 保持播放，答题存档前后逐项相等，密钥没有进入存储。

## 主观题评分实现与边界

同一 BYOK 客户端发送级别、题型、完整原文和英文答案。作文按切题、内容、结构和语言作总体印象评价；翻译先核对中文信息的准确完整、遗漏/误译/增译，再评价语言。四级/六级语言要求分别提示，统一 15 分档次。原则参考 [教育考试院公开大纲](https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)，提示词为本项目的学习用途整理，不冒充官方阅卷细则。

模型收到 JSON Schema 及仅输出对应 JSON 的格式要求，题目和答案明确标为待评价数据，不执行其中指令。客户端校验字段、0–15 整数、档次一致、引用真实原句、中文对照和明显逻辑矛盾；不合格结果整体拒绝，不显示假分数。每项保存与对应原文、答案、级别、模型及时间关联的快照。比较文本版本判断过期，无额外存储或密钥字段。

输入限制为原文 12000、答案 20000 字符；输出内容 24000 字符，服务响应体 256000 字节；批改 60 秒超时、划词 25 秒超时，均可取消且不自动重试。未配置或输入不完整时不请求；失败保留草稿。评分不会替换作答，也不合并到客观题得分或转换成 710 分。

## 数据与使用限制

- 真题有 93 个试卷 PDF、90 个答案 PDF、58 个 MP3，尚无可信结构化题干和机读答案。通用答题卡须先核对实际题号，合卷、缺页以原文件为准；不能自动评分。
- 原创题完整覆盖操作流程，但不是正式考试难度模拟，也不提供官方分数。作文/翻译默认保存，用户点击后可请求独立的 0–15 AI 模拟评分，不换算官方报道分。
- 扫描 PDF 没有可选文字，明确降级，不执行 OCR。外部 PDF 的跨域限制无法由客户端绕过。
- AI 有条件可用：用户填地址、Key、Model；服务必须允许浏览器 CORS，并返回可通过约定校验的 JSON 评分。Key 只在内存，刷新需重填。不能跨域的服务须使用受用户控制的可信后端。外部提供商的实际账户、额度与模型质量未验证。客户端可检查引用和结构，不能证明模型对语义与分数的判断正确。
- `npm audit --omit=dev` 报告既有依赖链 **6 项告警（1 moderate、4 high、1 critical）**，涉及 Next、其构建依赖等；PDF.js 未出现在该次报告中。本次未升级既有框架版本，也未据此断言所有告警均可经当前静态页面触发。

数据补齐须先人工核验授权与答案，再使用已有校验器导入；既有依赖告警应单独安排升级验证。本次没有待补写的功能代码。
